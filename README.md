#### 🚀 [StaffOps](https://github.com/StaffOps)

An open-source suite of operational tooling for Kubernetes platforms, born from day-to-day platform and SRE work: the things I wished existed, built to be reused.

- [aigent-squad](https://github.com/StaffOps/aigent-squad): a multi-agent system (1 supervisor + 6 specialists) for AWS/Kubernetes operations, with ChatOps on Slack, read-only by default
- [otel-libs](https://github.com/StaffOps/otel-libs): standardized OpenTelemetry instrumentation libraries
- [anomaly-detection](https://github.com/StaffOps/anomaly-detection): distributed anomaly detection for Kubernetes clusters, statistical (Go) plus ML forecasting (Python)
- [maturity-score-card](https://github.com/StaffOps/maturity-score-card): a single 0–100 score for how well an application is built, shipped and run

#### 🎓 [StaffOps Mentoring](https://github.com/StaffOps-Mentoring)

A mentoring program for people moving into infrastructure, DevOps and SRE, built on hands-on labs that are **verifiable**: each lab sets up a broken scenario, you fix it, and a script checks your work item by item, the way production would.

- Tracks: **Linux** (RHCSA-level, 147 labs) → **Docker** → **CI/CD** with GitHub Actions → **Kubernetes**
- Portal: [mentoria.staffops.space](https://mentoria.staffops.space)
